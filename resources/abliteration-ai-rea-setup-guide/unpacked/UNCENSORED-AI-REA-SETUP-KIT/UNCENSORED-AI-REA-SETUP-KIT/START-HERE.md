# Start here

Open **UNCENSORED-AI-REA-SETUP-GUIDE.pdf** first. You can read it without installing anything.

This is the setup resource promised near 6:32 in Mark's REA/Tempo video. It covers DeepSeek Harness, Abliteration AI, REA and Ghidra on an Apple silicon Mac.

## Pick your route

- New installation: follow the guide's pinned 0.2.0-rc.2 route and use examples/dsh-0.2-cordis.patch.example.yml.
- Recorded installation: the video used 0.1.1-rc.2. Use examples/dsh-0.1-settings.example.yaml for that version.
- Want an agent to do setup? Give it AGENT-SETUP-PROMPT.md and SETUP-GUIDE.md. Enter your API key privately yourself.

## Files

- UNCENSORED-AI-REA-SETUP-GUIDE.pdf: the complete guide.
- SETUP-GUIDE.md: its editable text, with clickable source links.
- AGENT-SETUP-PROMPT.md: copy-ready instructions for your coding agent.
- examples/: two version-specific provider examples and Ghidra shell settings.
- VERIFICATION.md: what was tested for this release, and what wasn't.
- MANIFEST.sha256: checksums for the package files.

The recorded request used abliterated-model-large; the API responses identified large-v2. The guide explains the difference. API usage is separate from this download. This package includes no model weights, application binaries, API keys, proprietary code or Tempo download.
