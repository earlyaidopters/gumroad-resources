## About

### Your own focus music app, free

Dreamlight is the focus music app from my video. It has 25 one-hour tracks made entirely with Python, motion art for every mood, and a player you actually own. It runs in your browser on Mac, Windows or Linux, on your phone's home screen, or as a desktop app that plays offline. There's also a lighter version you can build inside Claude with one prompt.

- 
The full app: The complete source as a ZIP, the same code that's open source on GitHub, plus a script that downloads all 25 tracks in one command.

- 
The setup prompt: Paste one prompt into Claude Code or Codex and it installs Dreamlight for you, then sets up the desktop app, the phone version or Google Calendar (it runs in the desktop app), whichever you pick.

- 
Every prompt from the video: The prompt that turns any Claude app into one you own, the Electron prompt for a desktop app, the Higgsfield art prompt, and a one-prompt Dreamlight you can build inside Claude.

- 
A visual guide: Six pages covering the four ways to run it, adding it to your iPhone or Android home screen, and how the music is made.

Every track is written by code, with no samples or outside audio, so the music is royalty-free and yours to use. Binaural tracks need headphones. Dreamlight is music for focus and relaxation, not a medical device.

What you need: A Mac or PC, an AI agent that can run commands on it (Claude Code or Codex), and about 3 GB of free space, or 7 GB with the desktop app. The music is 2.2 GB, so it downloads from GitHub during setup instead of sitting in the ZIP. The phone version needs a hosted copy and an internet connection.

Free and open source under the MIT license.
