# What You Get

- 
The Polyskill Meta-Skill: A ready-to-install skill workspace. Drop it in, and you can invoke /polyskill in Claude Code or $polyskill in Codex with plain English. The skill picks up your request and runs the right commands behind the scenes.

- 
The Hello-Skill Example: A worked example that exercises every cross-runtime primitive (dynamic injection, MCP dependencies, allowed-tools, front-loaded descriptions). Use it as a template the first time you author your own portable skill.

- 
Step-by-Step Install Guide: 3 commands, ~3 minutes. Get the CLI from the public GitHub repo, run polyskill install once, and the optimizer is now a skill in both your runtimes.

Polyskill solves a real problem most skill creators have not noticed yet. A skill written for Claude Code does not behave the same way when you drop it into Codex. The two share the open Agent Skills standard, but each adds runtime-specific extensions the other ignores. Polyskill is the universal adapter. You write the skill once in a portable format, polyskill compiles it down into the optimal version for each runtime, and both runtimes treat it natively.

- Take an existing Codex skill and make it work in Claude Code
- Author a brand-new skill that targets both runtimes from one source
- Install one skill in both runtimes from a single command
