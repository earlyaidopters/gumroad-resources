# Setup & Credential Instructions for n8n VC Workflows

This document provides comprehensive instructions for setting up and configuring the n8n workflows for venture capital firm operations. Follow these steps to properly set up each workflow with the necessary credentials and connections.

## General Setup Requirements

### 1. n8n Installation

Before implementing any workflows, ensure you have n8n installed and running:

```bash
# Install n8n globally using npm
npm install n8n -g

# Start n8n
n8n start
```

Alternatively, you can use Docker:

```bash
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```

Access the n8n interface at `http://localhost:5678`.

### 2. Credential Management

n8n securely stores credentials for various services. To add credentials:

1. Navigate to the **Credentials** section in the n8n sidebar
2. Click **New Credential**
3. Select the appropriate credential type
4. Enter the required information
5. Click **Save**

## Workflow-Specific Credentials

### Workflow 1: Deal Sourcing & Lead Capture

#### Required Credentials:
1. **LinkedIn API**
   - Credential Type: OAuth2
   - Required Information:
     - Client ID
     - Client Secret
     - Scope: `r_emailaddress,r_liteprofile,w_member_social`
   - Setup Instructions:
     - Create a LinkedIn Developer account at https://developer.linkedin.com/
     - Create a new application
     - Configure OAuth 2.0 settings with redirect URL: `http://localhost:5678/rest/oauth2-credential/callback`

2. **Website Form Integration**
   - Credential Type: Webhook
   - Required Information:
     - Webhook URL (automatically generated by n8n)
   - Setup Instructions:
     - Create a Form Trigger node in n8n
     - Copy the generated webhook URL
     - Integrate this URL with your website form submission handler

3. **CRM Integration (e.g., Agile CRM)**
   - Credential Type: API Key
   - Required Information:
     - API Key
     - Email
     - Domain
   - Setup Instructions:
     - Log in to your CRM admin panel
     - Navigate to Developer/API section
     - Generate API key and note your domain

4. **Slack**
   - Credential Type: OAuth2
   - Required Information:
     - Client ID
     - Client Secret
     - Scope: `chat:write,channels:read,channels:write`
   - Setup Instructions:
     - Create a Slack App at https://api.slack.com/apps
     - Enable OAuth and add required scopes
     - Install app to workspace
     - Copy Client ID and Client Secret

## Template Files Setup

Each workflow requires specific template files to function properly. These templates are provided in the `/templates` directory for each workflow. To set up:

1. Create the necessary Google Sheets, Google Docs, and other template files
2. Copy the provided templates to your Google Drive
3. Update the workflow configurations to point to your copies of the templates

## Webhook Configuration

For workflows using webhooks (Form Triggers, HTTP Request nodes):

1. Deploy n8n on a server with a public IP or use a service like ngrok for local testing
2. Update webhook URLs in the workflow to use your public URL
3. Test webhook connectivity before deploying workflows

## Environment Variables

For enhanced security, use environment variables for sensitive information:

1. Create a `.env` file in your n8n root directory
2. Add environment variables in the format: `KEY=value`
3. Reference these variables in workflows using the Expression Editor: `{{$env.KEY}}`

## Testing Your Setup

Before full deployment:

1. Test each credential connection individually
2. Run workflows in manual mode first to verify proper operation
3. Enable error notifications to monitor for issues
4. Start with test data before processing actual business information

## Troubleshooting Common Issues

- **Authentication Errors**: Verify credentials and check for expired tokens
- **Webhook Issues**: Ensure public URL is accessible and properly configured
- **Rate Limiting**: Implement appropriate delays between API calls
- **Data Format Problems**: Verify data structure matches expected format in nodes

For additional assistance, refer to the n8n documentation at https://docs.n8n.io/
