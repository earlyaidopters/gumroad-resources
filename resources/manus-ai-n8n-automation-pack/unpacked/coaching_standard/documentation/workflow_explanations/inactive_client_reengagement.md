# Inactive Client Re-engagement Automation Workflow Explanation

## Overview

The Inactive Client Re-engagement Automation workflow is designed to identify and reconnect with clients who haven't scheduled coaching sessions recently. This workflow automatically detects inactive clients, sends personalized re-engagement emails, tracks responses, and helps you maintain ongoing relationships with your client base to reduce churn and increase retention.

## Workflow Structure

The workflow consists of the following key components:

1. **Schedule Trigger**: Initiates the workflow on a regular schedule
2. **Inactive Client Detection**: Identifies clients who haven't had sessions in a defined period
3. **Personalized Outreach**: Generates and sends tailored re-engagement emails
4. **Response Tracking**: Monitors and records client responses
5. **Notification**: Alerts you about re-engagement efforts and responses

## Detailed Node Explanation

### 1. Schedule Trigger

This node initiates the workflow on a predetermined schedule. By default, it's set to run once per week (Mondays at 9:00 AM).

**Configuration:**
- Type: Schedule Trigger
- Schedule: Every Monday at 9:00 AM
- You can modify this schedule based on your preferred frequency for re-engagement efforts

### 2. Google Sheets - Get Active Clients

This node retrieves your list of active clients from Google Sheets.

**Configuration:**
- Type: Google Sheets
- Operation: Get All Rows
- Sheet Name: Clients
- Filter: Status = "Active"

### 3. Google Sheets - Get All Sessions

This node retrieves all client sessions to analyze activity patterns.

**Configuration:**
- Type: Google Sheets
- Operation: Get All Rows
- Sheet Name: Client Sessions
- No filter (retrieves all sessions)

### 4. Identify Inactive Clients

This node analyzes the client and session data to identify inactive clients.

**Configuration:**
- Type: Code (JavaScript)
- Function: 
  - Identifies clients with no sessions in the last 30 days
  - Excludes clients who have recently received re-engagement emails
  - Calculates days since last session for each client
  - Returns a list of inactive clients with relevant details

### 5. Any Inactive Clients?

This node checks if there are any inactive clients to contact.

**Configuration:**
- Type: IF
- Condition: Checks if the inactive clients array length is greater than 0
- Routes the workflow based on whether there are inactive clients to process

### 6. Extract Clients Array

This node prepares the inactive clients data for processing.

**Configuration:**
- Type: Code (JavaScript)
- Function: Extracts the array of inactive clients for batch processing

### 7. Split Into Individual Clients

This node separates the list of inactive clients into individual items for processing.

**Configuration:**
- Type: Split In Batches
- Batch Size: 1
- This allows individual processing of each inactive client

### 8. OpenAI - Generate Re-engagement Email

This node uses OpenAI's GPT-4 to create a personalized re-engagement email for each inactive client.

**Configuration:**
- Type: OpenAI
- Model: GPT-4
- Temperature: 0.7
- Prompt: Structured to create a personalized re-engagement email that:
  - Notes the client's absence without being pushy
  - Reminds them of the value they were getting from coaching
  - References their specific goals
  - Offers a special "re-engagement" session or discount
  - Includes a clear call-to-action

### 9. Gmail - Send Re-engagement Email

This node sends the personalized re-engagement email to the inactive client.

**Configuration:**
- Type: Gmail
- Operation: Send Email
- To: Client's email address
- Subject: "Let's Reconnect: Special Coaching Offer for [Client Name]"
- Content: HTML-formatted email generated by OpenAI

### 10. Google Sheets - Update Client

This node updates the client record to track re-engagement attempts.

**Configuration:**
- Type: Google Sheets
- Operation: Update Row
- Sheet Name: Clients
- Data: Last Re-engagement Date = [Current Date], Re-engagement Count = [Incremented]
- Row: Identified by Row Number from the original query

### 11. Google Sheets - Log Re-engagement

This node records the re-engagement attempt in a dedicated tracking spreadsheet.

**Configuration:**
- Type: Google Sheets
- Operation: Append Row
- Sheet Name: Re-engagement Tracking
- Data: Client name, email, date sent, days inactive, re-engagement count, status

### 12. All Clients Processed?

This node checks if all inactive clients have been processed.

**Configuration:**
- Type: IF
- Condition: Checks if there are no more items left to process
- Routes back to process more clients or continues to notification

### 13. Slack - Send Notification

This node sends a notification about the batch of re-engagement emails.

**Configuration:**
- Type: Slack
- Channel: Your designated client channel
- Message: Summary of how many re-engagement emails were sent

### 14. Webhook - Track Response

This node creates an endpoint that receives responses to re-engagement efforts.

**Configuration:**
- Type: Webhook
- Method: POST
- Path: track-reengagement-response
- Response: JSON
- This endpoint receives client responses with details like email, response type, and notes

### 15. Validate Response Data

This node validates the incoming response data.

**Configuration:**
- Type: Code (JavaScript)
- Function: Validates required fields (client email, response type)
- Returns error if validation fails

### 16. Is Valid Response?

This node checks if the response validation was successful.

**Configuration:**
- Type: IF
- Condition: Checks if the success property is true
- Routes the workflow based on validation result

### 17. Google Sheets - Find Re-engagement Record

This node locates the original re-engagement record for the responding client.

**Configuration:**
- Type: Google Sheets
- Operation: Get All Rows
- Sheet Name: Re-engagement Tracking
- Filter: Client Email = [Response Email] AND Status = "Sent"

### 18. Google Sheets - Update Re-engagement Status

This node updates the re-engagement record with the client's response.

**Configuration:**
- Type: Google Sheets
- Operation: Update Row
- Sheet Name: Re-engagement Tracking
- Data: Status = [Response Type], Response Date = [Current Date], Notes = [Response Notes]
- Row: Identified by Row Number from the found record

### 19. Slack - Notify About Response

This node sends you a notification about the client's response.

**Configuration:**
- Type: Slack
- Channel: Your designated client channel
- Message: Alert with client name, response type, and any notes

### 20. Respond - Success

This node sends a success response back to the tracking system.

**Configuration:**
- Type: Respond to Webhook
- Response: JSON with success message
- Status: 200 OK

### 21. Respond - Error

This node sends an error response if validation fails.

**Configuration:**
- Type: Respond to Webhook
- Response: JSON with error message
- Status: 400 Bad Request

## Workflow Logic and Data Flow

The workflow operates in two distinct parts:

**Part 1: Sending Re-engagement Emails**
1. The schedule trigger runs weekly to identify inactive clients
2. Clients who haven't had sessions in 30+ days and haven't recently received re-engagement emails are identified
3. For each inactive client:
   - A personalized re-engagement email is generated
   - The email is sent to the client
   - The client record is updated to track the re-engagement attempt
   - The attempt is logged in the re-engagement tracking spreadsheet
4. A notification summarizes the batch of sent re-engagement emails

**Part 2: Tracking Responses**
1. The webhook receives response tracking information
2. The response data is validated
3. If validation fails, an error response is sent
4. If validation succeeds:
   - The original re-engagement record is located
   - The record is updated with the response details
   - You receive a Slack notification about the response
   - A success response is sent to the tracking system

## Customization Options

You can customize this workflow in several ways:

1. **Inactivity Definition**: Adjust the timeframe that defines an "inactive" client (30 days by default)
2. **Re-engagement Frequency**: Modify how often you check for inactive clients
3. **Email Content**: Customize the tone and offers in re-engagement emails
4. **Response Categories**: Define specific response types to track (interested, not interested, schedule later, etc.)
5. **Follow-up Actions**: Add automated follow-up steps based on different response types

## Error Handling

The workflow includes error handling at several points:

1. Clients who have recently received re-engagement emails are automatically excluded
2. Validation of all required response fields
3. Clear error messages for tracking systems
4. If a client record cannot be found, the system logs the error but still records the response
5. All errors are logged for troubleshooting

## Integration Points

This workflow integrates with:

1. **Google Sheets**: For client database, session records, and re-engagement tracking
2. **OpenAI API**: For personalized email generation
3. **Gmail**: For email delivery
4. **Response Tracking System**: Via webhook (can be integrated with email click tracking, forms, etc.)
5. **Slack**: For notifications

## Performance Considerations

- The weekly check typically takes 1-2 minutes depending on client database size
- Processing each inactive client takes a few seconds
- The webhook has a timeout of 120 seconds, which is more than sufficient

## Best Practices

1. Keep re-engagement emails warm and non-pushy
2. Offer genuine value in your re-engagement attempts (special session, resource, etc.)
3. Limit re-engagement attempts to avoid appearing desperate (max 3-4 attempts per client)
4. Space re-engagement attempts appropriately (at least 30 days between attempts)
5. Analyze response patterns to improve your retention strategy
6. Personally follow up with clients who show interest in returning
7. Use re-engagement data to identify potential issues in your coaching services

This workflow automates the process of identifying and reconnecting with inactive clients, helping you maintain a healthy client base and reduce churn. The systematic approach ensures no client falls through the cracks while the personalized outreach maintains the relationship-focused nature of coaching services.
