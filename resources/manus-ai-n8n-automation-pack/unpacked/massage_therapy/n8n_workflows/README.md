# N8n Workflows for Massage Therapy Business

This package contains 10 comprehensive n8n workflows designed specifically for massage therapy business operations. Each workflow is fully documented and ready to import into your n8n instance.

## Package Contents

1. **Workflow JSON Files**: Ready-to-import workflow definitions
2. **Workflow Documentation**: Detailed explanations of each workflow
3. **Setup Instructions**: Step-by-step guide for implementation

## Workflows Included

1. **Lead Capture & Qualification System**
   - Captures website leads and scores them based on predefined criteria
   - Routes qualified leads to appropriate follow-up actions
   - Tracks lead sources and conversion rates

2. **Appointment Scheduling Automation**
   - Enables client self-booking with real-time availability checking
   - Syncs with Google Calendar to prevent double-bookings
   - Sends booking confirmations to clients and therapists

3. **Appointment Reminder Sequence**
   - Sends automated SMS/email reminders at configurable intervals
   - Provides easy rescheduling options for clients
   - Reduces no-shows and late cancellations

4. **Client Intake Form Processing**
   - Automates collection and secure storage of client health information
   - Validates form completeness and flags important health concerns
   - Creates client profiles in your database

5. **Post-Appointment Follow-Up System**
   - Sends thank-you emails with review requests
   - Offers rebooking incentives based on service type
   - Collects and analyzes client feedback

6. **Inactive Client Re-engagement**
   - Identifies clients inactive for 60+ days
   - Sends personalized re-engagement sequences with special offers
   - Tracks re-engagement campaign effectiveness

7. **Therapist Schedule Management**
   - Ensures optimal scheduling based on therapist availability
   - Prevents double-bookings and scheduling conflicts
   - Notifies therapists of schedule changes

8. **Marketing Campaign Automation**
   - Schedules social media content across multiple platforms
   - Tracks campaign effectiveness with engagement metrics
   - Generates performance reports for marketing initiatives

9. **Client Birthday/Anniversary Recognition**
   - Sends personalized messages with special offers on client special dates
   - Tracks offer redemption rates
   - Strengthens client relationships through personalized engagement

10. **Business Analytics Dashboard**
    - Tracks key business metrics (appointments, revenue, client retention)
    - Generates weekly and monthly performance reports
    - Provides actionable insights for business optimization

## Implementation Requirements

- n8n instance (self-hosted or cloud)
- Google Workspace (Gmail, Calendar, Sheets)
- Optional: Social media accounts for marketing automation
- Optional: Twilio account for SMS capabilities

## Getting Started

1. Review the setup instructions document for detailed implementation steps
2. Import the workflow JSON files into your n8n instance
3. Configure the required credentials and connections
4. Customize the workflows to match your specific business needs
5. Test each workflow thoroughly before full deployment

For detailed implementation instructions, please refer to the setup_instructions.md file included in this package.
