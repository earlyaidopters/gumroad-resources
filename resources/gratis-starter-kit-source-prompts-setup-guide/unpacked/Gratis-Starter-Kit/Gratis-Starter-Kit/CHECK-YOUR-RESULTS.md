# Check the result, not just the answer

| Check | Result / notes |
| --- | --- |
| OS and CPU architecture match the documented target | |
| Exact source commit or release recorded | |
| Correct app opens without changing another app | |
| Test uses a disposable conversation/profile | |
| Selected provider is signed in | |
| One real response completes; no mock claimed as live | |
| Agent name/avatar and chat survive restart | |
| Stop interrupts an active response | |
| Optional tools checked only when actually configured | |
| Cost, hosting and provider limits understood | |
| Personal data and credentials absent from shared logs | |

For a research task, open the sources. For a file task, open the saved file. For an app, launch the actual package. For an automation, test the workflow manually before adding a schedule. Record **not tested** when that is the truth.
