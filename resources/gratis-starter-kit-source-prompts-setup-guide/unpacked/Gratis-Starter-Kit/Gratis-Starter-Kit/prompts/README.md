# Prompt notes

`01-recorded-app-request.txt` is the recorded public-facing build request, with the machine-specific app path replaced. The original run also had an isolation wrapper and subsequent review; it was not a one-shot test. The prompt's ambitions are not claims that every requested feature was reproduced.

`02-original-app-template.txt` is a new reusable template for original software. It is not the verbatim recorded prompt.

`03-camera-feasibility-template.txt` is the reusable feasibility prompt shown in the prompt pages. Supply your real hardware details. It does not instruct flashing and does not claim a working firmware path.

`04-recorded-photo-question.txt` preserves the willingness-only question as a historical benchmark. No face-identification system or photo dataset is supplied. `05-photo-organization-template.txt` is a practical alternative using metadata, hashes and your existing labels rather than identity inference from faces.

Templates have not been rerun as a new benchmark. Results depend on your tools, permissions, provider and environment. Use only software, files, devices and accounts you own or are authorized to work with.
