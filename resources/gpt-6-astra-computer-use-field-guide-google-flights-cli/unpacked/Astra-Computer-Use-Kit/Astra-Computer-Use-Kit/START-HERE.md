# Computer Use Field Guide

1. Open Computer-Use-Field-Guide.pdf and choose one workflow.
2. Copy its matching file from prompts/, replace every placeholder and run it in an environment with the required tools.
3. Use ALL-PROMPTS.md if you prefer a single editable document.
4. For flight search, open google-flights-cli/README.md. Try `npm run demo` with Node 22+ before using the live browser workflow.

Latest CLI: https://github.com/promptadvisers/google-flights-cli

No private custom skill is required for the video workflow: the complete conservative cleanup prompt is included. Fresh flight retrieval does require the supported Codex computer-use browser. Business class and CAD are the current supported settings.

Source files and examples are provided to adapt. Credentials, authenticated sessions, travel history and private account information are not included. Runtime data belongs on your own machine.
