## About

### Put computer use to work
Take the five workflows from the video and adapt them to your own apps, files and projects. Each prompt spells out the job, the boundaries and the proof of completion.

- 
Field guide: A beautifully designed 13-page PDF with setup notes, reusable prompts, completion checks and ideas for adapting each workflow.

- 
Copy-ready prompts: Nine separate text files plus one combined Markdown file. Includes the five main workflows, flight-search expansion, conservative Descript cleanup, a benchmark prompt and a reusable template.

- 
Google Flights CLI: Full MIT-licensed source, a visual README, architecture diagrams, example requests, synthetic tests and an offline JSON/CSV demo. The public GitHub repository is included below.

- 
Five workflows: Turn manual searches into a tool; test MCPs, APIs and integrations inside their host app; let one agent test another; finish a video-editing handoff; change a phone setting from your Mac.
