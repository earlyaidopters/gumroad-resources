## **Web App Prompt**

```
Create a visually stunning, fully functional prompt engineering assistant web application with the following specifications:

1. TECHNICAL REQUIREMENTS:
   - Use vanilla JavaScript, HTML and CSS only (NO external dependencies or frameworks)
   - Include all code within a single HTML file (fully self-contained)
   - Ensure all JavaScript and styles are embedded within the HTML
   - Implement actual working functionality, not just UI mockups

2. VISUAL DESIGN:
   - Create a unique, premium-looking interface with a distinctive visual identity
   - Use a custom color scheme with rich gradients and subtle animations
   - Implement a modern, asymmetrical layout rather than standard card grids
   - Add micro-interactions like hover effects, subtle animations, and visual feedback
   - Include custom illustrations or icons (using SVG directly in the HTML)

3. CORE FUNCTIONALITY:
   - Implement a real-time prompt analysis engine that evaluates and scores prompts
   - Create dynamic template system that inserts content into the editor
   - Build interactive guidance that responds to what the user is typing
   - Include local storage to save user's work in progress
   - Implement actual copy-to-clipboard functionality
   - Add exportable formats (text, markdown)

4. USER EXPERIENCE:
   - Design with a focus on intuitive workflow from template to finished prompt
   - Add visual progress indicators showing prompt quality improvements
   - Include interactive tooltips explaining prompt engineering concepts
   - Create smooth transitions between application states
   - Implement responsive design that works on all screen sizes

The application should be something I'd actually want to use daily, with attention to both aesthetics and functionality that goes beyond a basic demo. Make it feel like a premium product rather than a simple example.
```
