## About

### Make Claude Code feel like yours
A little pet while Claude works. A map of the files it touches. A timeline of its helpers. A tray for the files it creates. This kit turns the mods from the walkthrough into something you can try, understand and make your own.
Start with one mod. See it work. Learn how to switch it off. Then build your own version with a complete, editable prompt.

- 
10 ready-to-inspect mods: Terminal Pet, Coral Skin, Context Meter, Repo Heatmap, Flight Recorder, Model Router, Output Tray, Changes Receipt, Session Bookmarks and Auto Handoff.

- 
Plain-English viewer guide: A 31-page PDF plus a searchable offline browser guide. Learn what each mod does, where to type the commands, and what should happen next.

- 
10 creation prompts: Full specifications with controls, off switches, failure cases and acceptance checks. Copy a prompt into Claude Code and adapt the idea to your own work.

- 
User and project setup: Separate instructions for one terminal trial, every project, one shared project, and a private project setting. Includes the desktop-versus-terminal explanation.

- 
A safe place to practice: A fictional demo project, repeatable task prompts and a launcher that creates a new folder instead of resetting your work.

- 
Editable source and a starter template: All ten plugins, their tests, a public GitHub repository, and a tiny example that shows how an event becomes a useful response.

- 
Clear off and removal instructions: Hide a panel, disable a plugin, or uninstall only this kit. No instruction to wipe your Claude settings.

Who this is for
You use Claude Code and want it to be easier to understand, easier to return to, or more fun to work in. You do not need to know how to code to follow the guide. You do need to be willing to paste a few labeled commands into Terminal.
