# Terminal Pet

Adds a pixel crab above the prompt. It reacts when Claude reads, writes, waits, finishes, or hits an error. Its belly reflects conversation fullness.

See [the complete guide](../../guides/01-terminal-pet.md) and [creation prompt](../../prompts/01-terminal-pet.txt).

Test from the kit root:
```bash
claude plugin validate plugins/terminal-pet
claude plugin test plugins/terminal-pet
```
