# Session Bookmarks

Saves a title and a short note with the project and session reference, so you can find the conversation again.

See [the complete guide](../../guides/09-session-bookmarks.md) and [creation prompt](../../prompts/09-session-bookmarks.txt).

```bash
claude plugin validate plugins/session-bookmarks
claude plugin test plugins/session-bookmarks
```
