# Coral Skin

Changes supported Claude Code message and tool rows to a coral, ink and cream style. Colored chips help you spot reads, edits and commands.

See [the complete guide](../../guides/02-coral-skin.md) and [creation prompt](../../prompts/02-coral-skin.txt).

Test from the kit root:
```bash
claude plugin validate plugins/coral-skin
claude plugin test plugins/coral-skin
```
