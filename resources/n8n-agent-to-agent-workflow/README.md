## About

What You’ll Get

- A powerful n8n workflow that dynamically builds AI agents on demand

- A secondary workflow that handles in-depth tasks triggered by the main flow.

- Automatically references relevant automations or connectors for a smooth handoff between flows

- 
Automation Knowledge Base Creation Script
- A specialized script that chunks and upserts different automations into Pinecone

- A link to 300 n8n AI automations from their marketplace

- Empowers your AI agent to consult an extensive library of pre-built automations, drastically cutting down setup time

- 
Deep Research Integration
- Built-in perplexity module for real-time documentation lookups and the latest n8n updates

- Ensures your AI agent stays current on new nodes, best practices, and feature changes in n8n

- 
Ready-to-Import Templates
- Straightforward JSON-based workflow files for both the main flow and sub flow, plus optional expansions

- Simply upload them to n8n and start generating AI agents tailored to your needs—no heavy coding required
