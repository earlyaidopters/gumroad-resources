## About

### Your private Codex back room

If you have ever vibe-coded a useful internal app and then realized every click needs another paid API call, this kit gives you a cleaner way to think about the backend.

You will learn how to put one private server-side bridge between a friendly app and the official Codex SDK, use the existing local Codex/ChatGPT sign-in for trusted owner-operated work, and keep a separate OpenAI API adapter ready for the moment your app becomes shared, deployed, or public.

- 
Human Guide: A polished 17-page plain-English PDF covering the mental model, authentication, headless execution, threads, permissions, data handling, migration, and common failures.

- 
Working Starter: A runnable TypeScript app with a loopback-only server, polished UI, Codex subscription adapter, OpenAI API adapter, validation, timeouts, concurrency limits, and tests.

- 
Three Mega Prompts: Build a new internal app, migrate an existing API-backed app, or audit an architecture with a skeptical security lens.

- 
Editable Diagrams: Three high-resolution SVG and PNG teaching assets showing the bridge, one-request cross-section, and backend switch.

- 
Security Boundaries: A short checklist that makes the difference between a genuinely private tool and accidentally placing a personal account behind public traffic.

- 
Agent-Readable Source: Markdown, source code, environment template, official-source list, and a definition of done your coding agent can follow without reverse-engineering the PDF.

The kit is built for one trusted owner first. It does not promise unlimited usage, bypass plan limits, or turn a personal ChatGPT account into a public API. Plans, permissions, limits, prices, terms, and SDK behavior can change; the current official sources are included.

Use the starter as a reference, or hand the entire folder to your coding agent and paste the included build prompt into a fresh task.
