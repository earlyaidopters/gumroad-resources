Important current facts reflected in this kit:

- OpenAI lists internal tools and workflows as a Codex SDK use case.
- The TypeScript SDK is server-side and currently requires Node.js 18 or later.
- Local Codex supports ChatGPT sign-in for subscription access and API-key sign-in for usage-based access.
- API-key usage is billed through the OpenAI Platform at standard API rates.
- Official authentication guidance says not to expose Codex execution in untrusted or public environments.
- Credentials must not be shared, and rate limits, restrictions, and safety controls must not be bypassed.
