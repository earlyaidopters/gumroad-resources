The Crash Course Guide (PDF): A 21-page visual companion to the video. Every concept from the course as a one-page spread with the exact diagram from the video plus plain-English notes.

- 
Link to Open Source Command Centre Shown (ODS)

- 
The Local AI Engineering Guide (HTML): The deep reference. 
- A full interactive guide you open in any browser with four views: the complete 15-section guide, a can-I-run-this calculator, a TLDR walkthrough of the whole build process, and an engine-by-engine decision guide.

The Can-I-Run-This Calculator: Built into the HTML guide.
