# Open Source AI Crash Course Kit

Thanks for grabbing the kit. Three resources inside:

## 1. The Crash Course Guide (PDF)

`open_source_ai_crash_course_guide.pdf`

The visual companion to the video. One page per concept, with the exact diagram from the video plus plain-English notes. Read it top to bottom once, then keep it as your reference for terms like quantization, KV cache, GGUF vs MLX, and tokens per second.

## 2. The Local AI Engineering Guide (HTML)

`local_ai_engineering_guide.html`

The deep reference. Double-click the file and it opens in your browser. No install, no internet needed after opening. Four views along the top:

- **The Guide**: the complete 15-section reference
- **Calculator**: pick your hardware, see which models fit and how fast they will run
- **TLDR Walkthrough**: the whole build process end to end, long form
- **Engines**: llama.cpp vs vLLM and friends, a decision guide

## 3. The Architecture Blueprints (HTML)

`architectures.html`

The plain-English companion. Ten local AI setups, from a single laptop to a home cluster, each with a system diagram and an everyday-language explanation of when to reach for it. Keep both HTML files in the same folder so the links between them work.

## Suggested path

1. Watch the video for the big picture.
2. Read the PDF once for the concepts.
3. Use the Calculator before downloading any model.
4. Keep the HTML guide open while you build your own command center.
