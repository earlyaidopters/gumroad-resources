## About

Use more models. Keep your workspace.
The companion resource for my Codex + Ollama video. Get the setup prompt, a practical guide and the workflow website in one place, so you can choose a suitable model, connect it and check that it actually completes a small task.

- 
Setup guide: An eight-page PDF covering the desktop integration, local versus cloud routes, a real file-write test, troubleshooting and cost per completed task.

- 
Copy-ready prompts: The exact prompt from the website, plus a guided version that checks your hardware, preserves existing settings and asks before downloads or paid changes.

- 
Verification test: A small, disposable file task to check tool execution and readback. A model appearing in a dropdown is only the first step.

- 
Task handoff template: Define the outcome, allowed changes, inputs, checks and budget before switching models.

- 
Companion website: Revisit the workflow diagrams and economics shown in the video through a direct link included in the kit and your download page.

Start with the PDF, or download the complete ZIP for all the prompts and templates. The kit explains the current desktop setup labels and links to the official documentation. Reviewed September 16, 2026.
You will need a compatible desktop app, Ollama and a suitable model. Local models need sufficient memory and disk space; cloud models may have separate usage costs. Model quality and tool support vary, and this kit does not promise a successful fresh install on every computer.
