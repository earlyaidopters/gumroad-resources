# Codex + Ollama Setup Kit

Start with CODEX-OLLAMA-SETUP-GUIDE.pdf. For the fastest no-install preview, open OPEN-WEBSITE.html and follow its link to the visual companion site.

## Your first useful result
1. Read pages 1-2 of the guide and choose local or cloud deliberately.
2. Paste 02-GUIDED-SETUP-PROMPT.txt into your existing working Codex task. Let it inspect first; review its proposed changes.
3. After connecting a model, open a fresh task with that model and paste 03-VERIFY-YOUR-MODEL.txt.
4. Confirm the real result.txt file contains 34113. For a local route, check the running model too.
5. Try one small real task with clear acceptance checks.

## Files
- CODEX-OLLAMA-SETUP-GUIDE.pdf: eight-page viewer guide, including troubleshooting and cost checks.
- 01-SETUP-PROMPT-FROM-SITE.txt: the original copy-ready prompt from the companion site.
- 02-GUIDED-SETUP-PROMPT.txt: a more deliberate inspect/approve/connect/verify version for your own machine.
- 03-VERIFY-YOUR-MODEL.txt: a small file-write/readback test.
- 04-TASK-HANDOFF-TEMPLATE.md: editable structure for passing one bounded task between models.
- 05-WEBSITE-AND-SOURCES.md: the promised site and official references.
- OPEN-WEBSITE.html: clickable website launcher; no installation needed.

The prompt is a reusable starting point, not an installer or a guarantee that every model supports every tool. Hardware, app versions and integrations vary. Cloud usage can cost money; local inference still uses your hardware and electricity. This kit does not provide an OpenAI subscription, model access credentials or unlimited frontier-model usage.
