# What You Get

- 
The /goal Cookbook (PDF): A polished 10-page guide containing the 5 ready-to-paste /goal prompts from the Self-Improving Agentic OS video, plus the 6-anchor framework that makes the difference between a /goal that finishes cleanly and a /goal that drifts.

- 
Prompt 1 - CLEAN: Audit ~/.claude end to end. Archive every skill that no longer earns its keep, dedupe rule contradictions, refresh CLAUDE.md, and write a senior-engineer-grade manifest of every change to AUDIT_REPORT.md.

- 
Prompt 2 - SHARPEN: Iterate one skill against a rubric you write. Claude scores its own output, finds the lowest-scoring criterion, edits the SKILL.md to fix it without regressing, and re-tests. Measurable improvement, not vibe-improvement.

- 
Prompt 3 - REVIVE: Scan ~/Projects, detect dormant folders by git age, attempt to run them, fix broken dependencies, rewrite the README in 3 sentences, log a verdict (alive, revived, unfixable) for each one to ALIVE.md.

- 
Prompt 4 - FORGE: Read the 50 most recent Claude Code session transcripts, find recurring prompt patterns that don't have a corresponding skill, and write new skills with proper YAML frontmatter and smoke tests.

- 
Prompt 5 - MAINTAIN: A /loop + /goal heartbeat that keeps your agentic OS clean on a 30-minute cycle while you sleep. The OS stays in equilibrium without manual maintenance.

- 
The 6 Anchors of a Great /goal Prompt: The hidden structure inside every prompt above. Once you see the anchors, you can write your own /goal prompts for any workflow.

- 
The Raw Prompts (5 .txt files): Each prompt as a standalone file with when-to-use, guardrails, common failure modes, and wake-up verification commands. Copy-paste ready.
