# Write the complete plan

New reusable prompt. Replace bracketed values and attach the referenced files.

---

Using the approved world brief, adapt the original 15-section plan to this project. Cover experience, visual contract, mission progression, interaction, factual teaching, architecture, asset production, device budgets, audio and accessibility, functional testing, visual assessment, release gates, hosting, production sequence and maintenance.

For every feature include its observable acceptance criterion, test method and fallback. Map each lesson to a player action, feedback, a retry and a transfer task. Pick one representative mission as the first milestone. Separate targets from measurements. List assumptions about tools, time, spend, licensing and hosting. Keep secrets out of project files. Produce an editable plan and a short list of unresolved decisions. Do not start the full world before we review the first milestone.
