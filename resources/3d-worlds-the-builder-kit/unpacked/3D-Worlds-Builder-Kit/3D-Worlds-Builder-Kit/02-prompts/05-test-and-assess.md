# Test function and assess quality

New reusable prompt. Replace bracketed values and attach the referenced files.

---

Audit the exact current build against the approved plan. First test behavior: every mission, wrong choices, hints, retries, completion, navigation, saves, reloads, resets, failed assets and blocked storage. Then assess teaching and presentation in the actual browser: legible text, clear feedback, character quality, camera framing, lighting, transitions, responsive layout, keyboard access, reduced motion and muted audio.

Use the release checklist. For each finding record severity, reproduction steps, expected versus actual result, evidence and affected build. Fix release blockers, retest the repaired path and check adjacent behavior. Separate automated coverage from manual observations. Do not mark a real device as tested if only browser emulation was used. Finish with a release recommendation and explicit remaining limitations.
