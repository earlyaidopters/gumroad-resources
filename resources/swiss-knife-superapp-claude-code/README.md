# What You Get

- 
9 Production-Ready Prompts: The exact prompts I used to build a complete Media Toolkit with Claude Code - step by step, in the order I executed them.

- 
Planning Prompt: Creates your implementation roadmap before writing a single line of code. This prevents wasted context and sets you up for a clean build.

- 
Project Setup Prompt: Scaffolds your entire FastAPI backend, dark-themed UI, and folder structure in one shot.

- 
Image Conversion Prompt: Build a tool that handles PNG, JPG, WEBP, GIF, BMP, TIFF, and even iPhone HEIC files. Bulk convert with a single click.

- 
PDF Tools Prompt: Merge multiple PDFs (with drag-to-reorder) and split PDFs by page range or into individual pages.

- 
Audio Extraction Prompt: Extract MP3, AAC, WAV, FLAC, or OGG audio from any video file. Choose your bitrate. No uploads to sketchy websites.

- 
Video Splitting Prompt: Split large videos into equal parts for Gemini uploads or long-form content. Handles multi-GB files without crashing.

- 
Video Compression Prompt: Three compression modes - target size, quality preset, or resolution. Turn a 4GB video into 100MB without losing your mind.

- 
AI Image Editor Prompt: Generate and edit images with Google Gemini. Style presets, aspect ratios, background removal, and custom prompts.

- 
Polish and Testing Prompt: Add toast notifications, loading states, error handling, and accessibility. Ship something production-ready.

Baton Pass Technique: The exact prompt structure I use to transfer context between Claude Code sessions without losing progress.
