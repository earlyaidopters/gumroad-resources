## About

Build a small AI specialist for one job you understand.
Get the complete prompt and practical guide from Mark Kashef’s Jev-inspired travel experiment. Explore the visual walkthrough, try the sample agency, and use the public starter to run a small training experiment on your own computer.
Included: 
• A copy-ready TXT prompt with editable task fields. 
• A polished one-page PDF with clickable links to the demo, public GitHub and full online guide. 
• The public visual walkthrough and interactive sample agency. 
• The MIT-licensed public starter, small example dataset and training recipe.
Start without installing anything. The browser demo uses recorded local-model outputs for 40 fictional holidays and nine photos. Budgets, preferences and photo selections update through application rules. The full V2 app, saved checkpoints and image integration are part of the community edition.
The measured result: 95.28% agreement for the local V2 model versus 98.61% for Jev on the same synthetic travel test. It improved on V1 and did not beat Jev. This is a learning resource, not a production booking service.
Free to download with a $0 minimum. Optional contributions support the work. Local hardware, storage, electricity, coding-assistant use and optional hosted benchmark calls have separate costs.
Original project code is MIT. Upstream code, models, fonts and datasets retain their own terms.
