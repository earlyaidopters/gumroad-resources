# Your Own Jev: start here

1. Open the visual guide: https://build-your-own-jev.markkashef.chatgpt.site
2. Try the sample agency: https://build-your-own-jev.markkashef.chatgpt.site/demo/
3. Read GUIDE.md, then copy prompts/TRAIN-MY-SPECIALIST.md into your coding assistant. Replace the bracketed fields with your own task.
4. For fresh local inference, get the source and companion-v2 release: https://github.com/earlyaidopters/away-together

The hosted demo uses recorded outputs for 40 fictional offers and nine photos. Your browser recomputes application rules when you change budgets, requirements or photo selection. It does not run or host the local models.

The full prompt and guide are included in this download. The model download is separate so you can learn and try the sample without a large installation.

Original code is MIT; upstream model/data licenses remain separate. The guide describes a narrow experiment, not a production booking system or a Jev win.
