## About

Stop rebuilding the same assistant somewhere else

Every new AI personal assistant makes your current setup feel obsolete. This free kit helps you step back, compare what actually changes, and decide whether you should stay put, use a managed product, choose an open-source runtime, or build an owned system.

- 
Open the live map: https://ai-assistant-house-map.markkashef.chatgpt.site/

- 
Interactive Map: The exact visual comparison from the video, including Grok Bot, Hermes Agent, Claude Cowork, ChatGPT Work, OpenClaw, an editable tier board, architecture cutaways, and the combined capability map.

- 
Research-Backed System Advisor: An importable skill with current product dossiers, adaptive questions, native Claude Code and Codex question-tool support, defaults-versus-ceiling analysis, user-specific scoring, a switching ledger, and a reversible test plan.

- 
Universal Prompt: A copy-ready version of the same decision interview for ChatGPT, Claude, Codex, or another capable assistant.

- 
Stay-First Logic: The advisor treats keeping your current setup as a real option and will not push you toward the newest product without a concrete reason.

- 
Reversible Next Step: Every recommendation ends with a 30 to 60 minute comparison and a seven-day pilot that do not destroy or prematurely migrate the system you already use.

- 
Current Research Dossiers: Detailed, dated analysis of Grok Bot, Hermes Agent, Claude Cowork, ChatGPT Work, OpenClaw, and the owned DIY path. The open-source dossiers include canonical releases and harness architecture. The managed-product dossiers cover runtime location, local-file reach, connectors, memory, orchestration, automation, permissions, usage, and trust boundaries.

The advisor dossiers were researched through 23 August 2026. Provider features, prices, limits, availability, and terms can change quickly, so the advisor verifies current first-party information again when browsing is available.

Open the map first, then run the system audit. You should finish with one clear recommendation, one runner-up, the reasons every other serious option lost, the layers you would need to rebuild, and the exact threshold that would make switching worthwhile.
