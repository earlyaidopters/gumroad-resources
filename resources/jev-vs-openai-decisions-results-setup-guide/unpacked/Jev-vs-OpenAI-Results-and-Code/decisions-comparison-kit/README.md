# Start here

Read Jev-vs-OpenAI-Decisions-Guide.pdf or GUIDE.md.

Run `python3 compare.py --dry-run` before the optional paid `--live` mode. No dependencies beyond Python 3.10+. Never put API keys in the kit.

The results folder contains all 100 frozen held-out runs (857 requests), not earlier development tests. Costs are dated estimates. Inspect benchmark-summary.json and the guide for limits. The script is a starter example, not the full benchmark harness.
