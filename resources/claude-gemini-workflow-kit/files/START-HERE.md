# Start here

## Try the kit in two chats

Open **Claude-Gemini-Prompts.txt** and find **Try it with two chats**. Copy the whole exercise between **COPY FROM HERE** and **END OF EXERCISE** into one Claude chat and one Gemini chat. Wait for both replies, then compare their choices and check each quote against the five interview lines.

## Use it on your own project

1. Open **Claude-Gemini-Workflow-Kit.pdf** and use **Choose a workflow** to find the pattern that fits your task.
2. Copy the original video prompt from **Claude-Gemini-Prompts.txt** or start with the role-specific prompts in **Claude-Gemini-Editable-Runbook.md**.
3. Fill out the short handoff brief, run the workflow, and check the result against the acceptance rule in the guide.

If you’re setting up T3 Code or Orca, use **Set up your first handoff** in the guide first. It includes the provider links and a way to check that each model can read and hand off the input you’re using.
