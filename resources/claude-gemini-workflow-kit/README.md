## About

### Claude + Gemini Workflow Kit

If you already use Claude and Gemini, give each one a different part of the job. The eight workflows from my video show you how to compare two feature decisions, build two parts of an app in parallel, or have one model recheck a bug the other just fixed.

- 
13-page workflow guide: See which model gets each job, what it needs from you, and what should come back. Every workflow has an example, a check you can run yourself, and a manual route.

- 
Editable runbook: Fill in a shared brief, give each role its own follow-up prompt, and check what each model sends back. The clip-picker example includes a shared time format and test cases for both agents.

- 
Copy-ready prompts: Get the eight prompts from the video, the workspace starter, and a fictional interview exercise you can paste into two chats.

- 
Start Here: Try the exercise first or connect your workspace using the guide. Includes links for T3 Code, Orca, MiroFish and Firecrawl.
