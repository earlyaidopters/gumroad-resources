## About

### What You Get

- 
Six copy-paste prompts, one for each pattern that almost every dynamic workflow is built from, pulled straight from Anthropic's own dynamic-workflows guide and adapted into prompts you can run today.

- 
Classify and act. Put one agent at the front door to sort and route a flood of incoming items, with a quarantine so the agents reading untrusted text can never take actions.

- 
Fan out and synthesize. Split a big job across many agents in clean separate contexts, then merge their structured outputs into one cited result.

- 
Adversarial verification. Have a separate agent attack and check each output, so nothing gets graded by the agent that made it.

- 
Generate and filter. Produce far more options than you need, then a separate judge keeps only the few that pass a rubric.

- 
Tournament. Rank a big pile by pairwise comparison, because picking a winner beats scoring out of ten.

- 
Loop until done. Keep spawning agents until a real stop condition is met, instead of a fixed number of passes.

Plus the composition capstone that chains three patterns into one machine, and the two control dials, goal for a hard stop and loop for a schedule, with a token cap you set in the prompt.
Each prompt tells you when to reach for it, runs as is, and is yours to adapt. The companion video walks through all six.
