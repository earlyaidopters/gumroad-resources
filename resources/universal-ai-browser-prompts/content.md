# Universal AI Browser Prompting Template

## Quick-Start Template Structure

```
"""[INSTRUCTION START]"""

PERSONA: As a [specific role with expertise]

AIM: [Clear single objective - what needs to be accomplished]

RECIPIENTS: For [who will use this information and why]

THEME: Focusing on [specific scope and boundaries]

CONTEXT: [Any background information, constraints, or existing data]

TASK:
1. [First specific action]
2. [Second specific action]
3. [Third specific action]

VERIFICATION: 
- Create 3 questions to verify your findings
- Answer each independently
- Flag any conflicting information

OUTPUT: 
- Format: [table/list/report/summary]
- Length: [specific word count or sections]
- Include: [must-have elements]
- Structure: [how to organize the information]

SOURCES: According to [specific trusted sources to reference]

"""[INSTRUCTION END]"""
```

## Simplified Templates by Use Case

## **For Research Tasks**

```
As a [role], research [topic] according to [trusted sources].

First, gather information about [aspect 1].
Then, analyze [aspect 2].
Finally, synthesize findings into [output format].

Create 3 verification questions about your findings and answer them independently.

Deliver results as [format] with [specific requirements].
```

## **For Multi-Tab Comparison**

```
Open [number] tabs:
@tab1: Navigate to [site1.com/specific-page]
@tab2: Navigate to [site2.com/specific-page]

Compare [specific elements] across @tab1 and @tab2.

Extract:
- [Data point 1] from each tab
- [Data point 2] from each tab
- [Differences/similarities]

Create comparison table showing [specific comparisons].
```

## **For Autonomous Actions**

```
Goal: [End result needed - not the steps]

Navigate to [website] and achieve [specific outcome].

Requirements:
- [Constraint 1]
- [Constraint 2]
- [Success criteria]

Stop before [final action] and await confirmation.

Provide screenshot/summary of ready state.
```

## **Progressive Prompting Sequence**

**Stage 1: Broad Context**

```
What are the main [topic/trends] in [industry/area]?
```

**Stage 2: Focused Research**

```
Focus specifically on [narrowed topic] from [time period].
According to [sources], what are the key findings?
```

**Stage 3: Specific Output**

```
Create a [specific format] comparing [specific elements].
Include [requirements] and organize by [structure].
Verify accuracy using [method].
```
