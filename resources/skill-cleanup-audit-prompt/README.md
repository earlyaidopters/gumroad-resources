## About

### Find the skills worth keeping

Collected more Claude and Codex skills than you use? Run this prompt on your own computer to inventory them, examine available usage history, and see what deserves a closer look.

- 
Ready-to-paste prompt: Audits your skills and proposes what to keep, merge, delete or review, with reasons.

- 
Offline report: Asks your assistant to build one HTML report with a usage heatmap, top-used-skills chart, overlap grid and merge ideas.

- 
Original video prompt: Includes the unchanged original alongside an edition with clearer counting and read-only instructions.

- 
Quick start and checklist: Explains where to run the prompt and the three questions to ask before changing your setup.

Use Claude Code or Codex with local file access. Results depend on which skills and session history the assistant can read. Missing history is marked unknown, not unused.

The audit is designed to leave your existing files unchanged and create only its report and JSON export. Review the recommendations before requesting any cleanup.

No additional skill installation is required. Download the kit, open START-HERE.md, and paste the .txt prompt into a new session.
