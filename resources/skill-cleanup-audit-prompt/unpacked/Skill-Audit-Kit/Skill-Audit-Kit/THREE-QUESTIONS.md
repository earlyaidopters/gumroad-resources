# The three questions for every skill

1. Does it run exact code? Keep useful, working scripts when repeatable execution is the point. Check whether another maintained tool already does that job.
2. Does it know something the model cannot know or search for? Your process, client requirements and writing preferences can be worth keeping. Check for overlap with your memory and project instructions.
3. Does a product or connector already make it obsolete? Verify that replacement covers the actual task before retiring the skill. Preserve any unique instructions.

Keep skills with a clear job. Merge useful skills that overlap. Review uncertain cases, including missing usage history, contradictions and unverified replacements. Mark redundant skills as cleanup candidates; do not remove them during the audit.

## Then merge

If two useful skills overlap, propose one leaner version and identify exactly what each contributes. Confirm dependencies and keep a backup before changing either original.

## Load skills just in time

For skills you need only occasionally, consider a separate folder that your tool does not automatically load. Ask your assistant to read the selected skill when you need it. Verify the tool's loading behavior first and do this only as a separate, approved cleanup step.
