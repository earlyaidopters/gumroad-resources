## About

# What You Get
The Fable Mindset is a free kit for keeping a piece of a frontier model after you lose access to it. When Fable 5 was switched off, the thing that made it special did not all disappear. The way it reasoned was recorded in your own conversation logs. This kit shows you how to pull that discipline out and point it at whatever model you are running today.

- 
The Fable Mindset (manual): A real operating manual distilled from more than 10,000 of my own Fable turns. The ethos, the full decision loop from ground to reason to act to observe to re-evaluate to verify to narrate, 12 principles, and an evidence appendix with the measured Fable vs Opus numbers. Point your model at this file and it inherits the habits. Ships as a clean PDF and the raw markdown.

- 
The extract-mindset skill: A reusable Claude Code skill that runs the whole pipeline on your own logs. It de-bloats a session, filters your history to a single model, measures the habits, and writes a mindset file for that model. Works on any model's turns, not just Fable.

- 
The scripts: debloat_jsonl.py strips a 32 MB transcript down to a 1.1 MB reasoning trace. extract_model_corpus.sh pulls one model's turns out of your entire history. analyze_discipline.py measures the habit rates so the comparison is evidence, not vibes. Copy-paste ready.

- 
Make it stick: The kit also tells you the honest part. A mindset file is best-effort, so it shows you where to set the effort level and how to wire a test hook so the one habit even a disciplined model is shaky at gets fixed automatically.

- 
The build prompts and the public dataset: The kit includes PROMPTS.md, the exact prompts that build all of this, so you can paste them into Claude Code and do it live. There is a shareable Fable_Mindset_public.md with the personal numbers genericized. And DATASET.md points you to an open archive of 4,665 real Fable 5 traces, with a tool to run the Fable versus Opus 4.8 delta even if you never had access to Fable.
