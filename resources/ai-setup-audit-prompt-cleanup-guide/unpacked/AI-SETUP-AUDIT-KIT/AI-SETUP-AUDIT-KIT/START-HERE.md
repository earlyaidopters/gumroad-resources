# Start here

This is the audit prompt from my video "Your AI Operating System Is a Mess", plus the guide I promised you can feed your AI so it helps you decide what to clean, retire and add.

## The fastest path (10 minutes of your time)

1. Open `AUDIT-PROMPT.md`, copy the prompt, and run it in Claude Code or Codex from your home folder.
2. Read the web page it makes. Start with the 10 changes.
3. In the same chat, attach `CLEANUP-GUIDE.md` and say "Use this guide to decide what to clean, retire and add. Start with the first change."
4. Approve one change at a time.
5. Set up `SCHEDULED-CLEANUP-PROMPT.md` as a weekly task so it stays clean.

## What's in here

| File | What it is |
| --- | --- |
| `AUDIT-PROMPT.md` | The exact prompt from the video, how to run it, and a one-tool version |
| `CLEANUP-GUIDE.md` | The guide for your AI, with the three questions, what to check, one source of truth, how to add new things |
| `SCHEDULED-CLEANUP-PROMPT.md` | The weekly check, plus setup steps for Codex and Claude |
| `AI-SETUP-AUDIT-GUIDE.pdf` | The same, laid out to read |

## What this kit never does

It installs nothing and adds nothing that loads every session. The audit only reads. The guide makes your AI ask before every change, back up first, and move things to an archive instead of deleting them.

Works with Claude Code and Codex. The ideas also work with Cursor, Gemini CLI and other assistants; name your tool in the prompt.
