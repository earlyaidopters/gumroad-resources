## About

### Make Claude work the way you want

Use Codex’s computer controls from Claude Code, then give one chat a team of real Claude sessions. This is the source and prompt bundle behind the two mods in the video.

What you get

Computer Use source: The mod, launcher and background helper, with app approvals and on/off controls. Threads source: Separate Claude sessions, chosen models, progress tracking, messages, plans and returned answers. Complete build prompts: Both detailed prompts, ready to copy, adapt and give to Claude. Quick-start PDF: A short visual guide to requirements, setup and your first two demos. Demo prompts and sample project: The Calculator-to-TextEdit opening, a two-helper walkthrough and a step-by-step plan. Setup and troubleshooting: A read-only prerequisite check, an explicit installer, plain-English documentation and included tests.

Start with the PDF, then extract the source ZIP and open START-HERE.md. You can install the existing code or use the prompts to rebuild and extend it. The interactive prompt breakdown is linked inside.

Requires a compatible mod-enabled Claude Code runtime. Computer Use additionally requires macOS and Codex computer use already configured in the ChatGPT Mac app. Threads needs tmux, terminal login and a trusted project. Provider runtimes, accounts and subscriptions are not included.

This is an unofficial integration. The code passed local automated tests; a fresh setup still needs the included live checks. Updates can require adjustments. Threads preserves the filmed bypass-permissions default, with instructions to change it. Computer Use starts with app approval enabled.

Free to download, with an optional contribution. Source includes an MIT license.
