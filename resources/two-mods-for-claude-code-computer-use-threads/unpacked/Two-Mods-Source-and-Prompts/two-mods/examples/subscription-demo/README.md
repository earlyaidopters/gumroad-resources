# Subscription demo

A deliberately imperfect sample for the Threads walkthrough. Review it rather than using it for billing.

`subscriptionTotal(monthlyPrice, months)` calculates the total for the requested number of months. If months is omitted, it assumes 12.

Examples promised by this README:
- `subscriptionTotal(149)` returns 1788.
- `subscriptionTotal(149, 6)` returns 894.

Your helpers should compare these promises to the implementation. No dependencies, private data or network calls are needed. The mismatch is intentional.
