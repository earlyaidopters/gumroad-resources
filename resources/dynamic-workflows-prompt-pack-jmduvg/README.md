# What You Get
Most people use Claude Code like a chatbot. These three prompts use it like a team. Each one points a dynamic workflow at your own world, your logs, the live discourse, your setup, fans agents out across it, and runs a second pass that verifies every finding before it reaches you. Each one hands back a clean, self-contained HTML report you can open anywhere.

- 
The Personalized Upgrade Guide: Point it at your own Claude Code session logs and it builds an Opus 4.7 to 4.8 upgrade guide tailored to how you actually work. It reads your real prompting patterns, the skills and tools you lean on, and where 4.7 gave you friction, then hands back before/after prompt upgrades and a prioritized migration checklist. Not a generic changelog. Your changelog.

- 
The Fact-Checked Research Report: Research what people are really reporting about a feature, with the actual X threads pulled in through Apify, not just recycled blog posts. It pitches its angles, fans agents across the web and those threads, fact-checks every claim, and reports how many survived versus got cut, with the source on every line and an honest section on what it could not confirm.

- 
The Setup Audit: Point a workflow at your global ~/.claude and your project .claude folder and it finds where you are not optimized: skills that overlap, rules that repeat or contradict each other, stale files, consolidation wins. Every finding is double-checked before it lands. You get a report grouped by type, each finding with the exact files and a one-line fix.

The 6-Part Framework: Every prompt is built on the same repeatable anatomy, corpus, role, extraction spec, fan-out, verify pass, HTML report, taught in plain English with a fill-in-the-blanks template so you can point a verified workflow at any pile of your own work.
Built for Claude Code on a paid plan (Opus 4.8, v2.1.154 or newer). 
The word "workflow" in your prompt is what spins up the team. Watch it run with /workflows, and press s to save any run as your own one-line command. Prompt 2 also uses an Apify X scraper.
