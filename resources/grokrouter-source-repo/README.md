## About

### GrokRouter is a public experiment

GrokRouter is an experimental source project I am actively building. It keeps Grok Bot as the interface while letting each Bot route its thinking through Codex or OpenRouter.

- 
Public Source Repo: Read the code, architecture, setup notes, tests, and ongoing updates on GitHub.

- 
How It Works Guide: A short visual PDF explaining the routing flow, installation boundary, provider and tool split, and the current way to try it.

I will keep adding to this as Grok Bot changes, more provider paths are tested, and the project becomes easier to use.

Start with the public repo, build it, test it, and follow the updates as the experiment evolves.
