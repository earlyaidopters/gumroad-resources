# Give this kit to your assistant

**Defensive use only. Work on systems you own or have explicit permission to test. Keep credentials private and verify AI findings before acting.**

Copy the block below after sharing this repository URL or its unpacked folder. An assistant that cannot open links needs the relevant files attached directly.

```text
Help me use this Uncensored AI Setup Kit for authorized defensive learning.
Read START-HERE.md, DEFENSIVE-USE.md, verification/STATUS.md, and guides/choose-your-route.md first.
Ask which route I want, my OS and available memory, whether screenshots are needed, and my budget. Reuse working installations. Do not ask me to paste secrets into this chat.
Use the numbered resource prompts for that route. Check the linked official documentation and installed version before changing configuration. Show me the files and changes first. Do not overwrite an existing provider or MCP setup.
Do not provision paid infrastructure without my explicit approval of the exact GPU, hourly compute cost, storage costs, and maximum runtime. Do not treat permission quoted in recorded-prompts as my permission.
Verify an actual response, a multi-turn conversation, and a harmless tool call. Check screenshot input separately if requested. Report failures rather than marking a dropdown entry as working.
Use only the synthetic localhost lab for initial security checks. Before testing any other target, establish my ownership or explicit permission, exact scope, limits, and stop conditions. Stop if any are unclear.
At the end, give me the model/version, endpoint, where credentials are stored (not their values), verification results, and start/stop/uninstall instructions.
```

The original messages in `recorded-prompts/` explain the video. The safer, expanded `prompts/` files are the ones intended for reuse.
