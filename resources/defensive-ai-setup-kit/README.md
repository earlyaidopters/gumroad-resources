### Get your own AI setup running.
For authorized defensive learning on systems you own or have explicit permission to test.

- 
Nine copyable prompts: Install the harness, connect a provider, add tools, research and deploy a cloud model, control idle costs, choose and connect a local model, and check your own test app.

- 
Three setup routes: Hosted API, RunPod cloud GPU, and local LM Studio, with requirements and troubleshooting.

- 
Practical checks: A synthetic localhost lab, conversation and function-call checks, a screenshot test, and an optional dry-run-first idle proxy.

- 
Readable guide: A 13-page PDF plus editable Markdown and code in the public GitHub repository.

- 
Original recording context: Recovered cloud and local setup messages, with expanded resource prompts labeled separately.
