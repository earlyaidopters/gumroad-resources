/unlock start here

Change how a local AI model behaves, keep the original, and see the proof side by side. Three steps, about five minutes once your computer is set up.

The fastest path

1Unzip Unlock-Skill.zip somewhere you can find it, such as your Downloads folder.
2Open Claude Code or Codex in that folder and paste this to install the skill. 
Install the Unlock skill from Unlock-Skill.zip into my skills folder so I can use it, then tell me how to invoke it.
Then start a new session so the skill loads.
3Paste the first prompt from Unlock-Prompts.txt. It is the exact prompt from the video. In Claude Code start it with /unlock, in Codex with $unlock. Your assistant checks your computer, asks the original model, edits a copy, compares both and opens a report.

What is in this download

Unlock-Skill.zipThe skill itself. A folder your assistant loads, with the machine check, setup, the one-command run and the report.
Unlock-Prompts.txtEvery prompt from the video, word for word, plus a slower step-by-step version.
Unlock-Full-Guide.pdfThe full guide in plain English, with the diagrams. Read this to understand what happens and why.
Unlock-Full-Guide.mdThe same guide as plain text. Paste it into any AI assistant and ask it to walk you through any part.

Before you start

You need Claude Code or Codex, plus the free tools git and uv. The tested setup is an Apple Silicon Mac. The edit needs about 14 GB of memory and about 25 GB of free disk. You do not have to check any of this yourself; the skill's first step checks your computer and tells you in plain words whether you are ready.

It edits models on your own computer only. Your original model is never changed. Read the "Honest limits" page of the guide before you rely on an edited model.
