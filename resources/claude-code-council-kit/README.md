## About

### What You Get
Optimist Strategist Agent: The visionary who maps out best-case scenarios and what needs to be true for success. Not a hype machine - grounded optimism with actionable pathways.
Devil's Advocate Agent: The critical thinker who stress-tests your assumptions, surfaces hidden risks, and identifies what could kill your idea before it kills your time.
Neutral Analyst Agent: The objective voice who synthesizes both perspectives, maps trade-offs, and anchors decisions to evidence.
Shared Reasoning Template: The markdown file where all agents document their thinking process, key insights, and conclusions. Your window into how each agent reached their verdict.
Council Setup Prompts: The exact prompts I used to create each agent and configure the council workflow in Claude Code.
Workflow Diagram: Visual breakdown of how the council operates and how agents pass the baton.
#### Why This Works
Claude Code subagents run in separate context windows. That means each agent starts fresh - no accumulated bias, no degraded quality from a bloated conversation. You get three independent opinions that Claude then synthesizes without its usual tendency to just agree with you.
