## About

### Meet your next little sidekick

Lil Token talks back, reacts to a head pat and changes his look with the music. This is the public build kit from my video, so you can build your own or take the pieces you want for a different project.

- 
Open-source code: The agent, gateway changes, firmware source and tests, with a GitHub link for updates.

- 
Editable faces: Expression PNGs, wardrobe assets and the generators that turn them into robot-ready files.

- 
Illustrated field guide: Ten pages covering the architecture, first setup, build process and troubleshooting.

- 
Build prompts: Three copy-ready guides for researching hardware, building the agent and testing it.

- 
The wall of shame: The real failure patterns, what caused them and where to look for a fix.

Start with the offline demo if you just want to explore. The physical build uses an M5Stack StackChan, a Mac and your own Claude and Fish Audio credentials. Search and app integrations are optional. Provider usage is billed to your own accounts.

Full source: View the public GitHub repository

Fish Audio sponsored the video that accompanies this kit.

Made for curious people who want to build something they can talk to.
