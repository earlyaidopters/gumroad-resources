Your first five minutes

  1. Unzip this kit into a folder.
  2. Open the field guide. The no-hardware route comes first.
  3. Run python3 source/examples/desk_demo.py.
  4. Open source/assets/faces to meet the expressions.
  5. For the real robot, follow source/docs/QUICKSTART.md.

Use your own API keys and a voice you have permission to use. Keep your local configuration, recordings and device backups private.
