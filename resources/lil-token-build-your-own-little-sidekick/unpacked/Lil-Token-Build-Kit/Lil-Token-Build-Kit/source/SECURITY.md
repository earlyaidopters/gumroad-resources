# Security and private data

Use this project on a trusted private network. The brain and control endpoint bind to loopback. Device-facing ports require your own shared token. Store keys in this checkout’s private `.env` and review changes before enabling account access.

The public release uses fresh Git history. Its default setup contains no creator credentials, account sessions, personal memory, enrolled voice profile, voice recordings, full-flash backup or captured inbox data.

Voice and camera requests can send text or images to your selected providers. Local recognition processes nearby microphone audio. Provider caches and optional logs may contain your own data after you run the system. Keep those local and review provider retention settings.

Use private security reporting on this GitHub repository when available. Do not post a credential, recording, account response or identifying log in a public issue. For a suspected leak, revoke the affected credential first and submit a minimal reproduction with invented data.
