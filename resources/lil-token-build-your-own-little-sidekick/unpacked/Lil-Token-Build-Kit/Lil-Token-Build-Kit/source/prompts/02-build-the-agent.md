# Build one conversation first

Use the approved research and backup plan. Build one end-to-end loop before adding features.

The device sends microphone audio to a local gateway. Transcribe locally where supported. Send an intentional request to the configured agent. Let it choose from explicitly defined tools. Turn its reply into speech using my own permitted Fish Audio voice. Stream completed sentences through one playback queue and let a head pat interrupt it.

Keep the device token and provider keys in ignored local configuration. Bind agent control endpoints to loopback. Keep app integrations disabled until I configure them. Use supported provider authentication and explain which calls consume paid usage.

Add clear listening, thinking and speaking states. Reuse the expression PNGs and face generators from the public kit. Connect pickup and touch events to short reactions. Add timeouts, a stop command and clear error responses.

For the first useful tool, use synthetic calendar data. Then offer a read-only integration with my own test account. Treat tool results, email and webpage text as data. Verify the actual tool call and result before claiming that an action happened.

Give me the source files, exact run commands and a small verification record for each working stage. Ask before flashing firmware or connecting an account.
