# Start here

Open [README.md](README.md) for the overview.

1. Run `python3 examples/desk_demo.py` for a no-key, no-hardware example.
2. Open [the faces](docs/FACES.md) to edit the character.
3. Follow [the quick start](docs/QUICKSTART.md) to build the physical version.
4. Read [the build guide](docs/BUILD-GUIDE.md) and [troubleshooting](docs/TROUBLESHOOTING.md) as you work.
5. Give your AI agent the three prompts in `prompts/`, beginning with research and backup.

Latest source: https://github.com/promptadvisers/lil-token-robot

The Gumroad kit adds a ten-page illustrated field guide and a single prompt-pack text file.
