## 3. Voice input and safe insertion

Another key/modifier while Option is held suppresses or cancels the hold until all shortcut keys are released. Use bounded recording duration and clean temporary audio on completion, failure or cancellation. Never log keystrokes. Show real microphone-level bars only while recording.
