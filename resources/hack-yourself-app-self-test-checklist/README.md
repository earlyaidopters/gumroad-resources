## About

Check the apps you build with AI, one feature at a time.

This kit includes the complete app self-test checklist from the video, a copy-ready starter prompt and a worksheet for recording the result and retesting a fix.

Start with a test copy, fictional records and two ordinary accounts. The guide covers private records, logins, usage costs, unsafe inputs, payments, connected AI and recovery.

You receive a printable PDF, an editable Markdown checklist, a plain-text prompt and a short START HERE guide. No coding experience is assumed for understanding the examples; running a test requires an assistant with the appropriate tools and your permission to test the app.

This is a practical starting point for controlled checks. It does not certify an app or promise a vulnerability will be found.
