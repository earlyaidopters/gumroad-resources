## About

Check the app you built with AI, keep the evidence, and work out what needs fixing first.

This is the complete companion kit for Hack Yourself. Start with two ordinary test accounts, compare what each can access, and have your assistant show you what happened. Then use the wider checklist to choose your next checks.

#### Inside the kit

- A polished 24-page field guide with five familiar feature stories and the complete 50-item checklist.

- Six copy-ready prompts: prepare the session, run one check, go deeper, review the evidence, fix and retest, and build a risk report.

- An offline risk-map webpage with clickable findings, urgent repairs, useful follow-ups, and protections that passed their checks.

- Three printable worksheets plus editable scope, evidence, coverage, retest, and JSON templates.

- A dedicated GitHub repository with editable sources, build scripts, checks, official references, and version notes.

The report starts empty. Its optional sample is explicitly fictional. It makes no network requests, and you can import a reviewed, redacted assessment without creating an account. No scan runs simply by opening the page.

Download the complete ZIP first. The PDFs, combined prompt file, checklist, starter prompt, disclaimer, and report page are also available separately. You do not need to install anything to read the guides or open the report. Executing a web test requires an assistant with working browser or HTTP tools and an app you are authorized to test. Model weights, paid credits, and hosting are not included.

#### Authorized defensive use only

Use systems you own or have explicit written permission to test, within the agreed scope. Use synthetic data and limited test accounts. Keep passwords, tokens, personal data, and private evidence out of public prompts, recordings, and reports. A prompt cannot enforce runtime permissions or spending limits.

AI can invent findings or miss weaknesses. The scenarios are teaching examples, not claims about your app or a client. A passing check covers the action tested and is not a security certification. The risk grid is a qualitative planning tool, not a measured probability or CVSS score.
