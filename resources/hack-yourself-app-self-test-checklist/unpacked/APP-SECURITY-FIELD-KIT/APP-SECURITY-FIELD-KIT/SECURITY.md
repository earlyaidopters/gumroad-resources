# Reporting a problem with this kit

For a documentation error or a non-sensitive report-template bug, open a GitHub issue with a minimal synthetic example, browser/version details, and steps to reproduce. Do not post credentials, private app URLs, client evidence, session logs, or personal information.

For a sensitive exposure, do not open a public issue. Use the private security-reporting option if GitHub offers it for this repository, or use the contact route at https://www.promptadvisers.com/ to request a private channel before sending details. Do not include the sensitive material in the initial contact message.

Findings about an app you assess belong with that app's authorized owner through the agreed disclosure process. This repository is not a reporting channel for third-party vulnerabilities and does not authorize additional testing.

---

For education and authorized defensive testing only. Use systems you own or have explicit written permission to test, within the agreed scope. Use synthetic data and limited test accounts. AI can miss issues or invent them; verify the evidence. A passed check is not a security certification. See DISCLAIMER.md and DEFENSIVE-USE.md for the full terms and limits.
