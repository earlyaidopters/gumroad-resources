# Check one feature of your own app

Open APP-SELF-TEST-CHECKLIST.pdf first. It includes the full checklist, the five examples from the video, a starter prompt and a results worksheet.

Use STARTER-PROMPT.txt when you are ready to try one bounded check. Replace YOUR_APP_URL and TEST_RECORD with a test copy you own and a fictional record. Provide two ordinary test accounts privately; never paste passwords or secret keys into public recordings or reports.

You need an assistant with browser or HTTP tools to run a web test. A text-only answer is a suggested plan, not an executed test. Use the setup you already trust, then check its actions and returned results yourself.

Start with one allowed action and one action that should be blocked. Keep the evidence. After a repair, repeat exactly the same check and confirm the normal action still works.

A passing check is evidence about that action, not a guarantee about the whole app. The five scenarios explain possible mistakes; they are not claims that every app has them.
