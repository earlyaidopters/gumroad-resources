Describe what you want in plain English, it picks the right model (Gemini image, GPT image, Veo, or one of four Chinese video lanes), rewrites your prompt for that specific model, calls the API, saves the file, and logs the exact cost to a running receipts ledger. No credits. No markup you can't see.

The Bench Studio repo, ready to clone: The full local creative studio, 37 curated model routes, a visual interface, a cost ledger, and MCP support, already public on GitHub. - 
The technical reference PDF: Built so you can hand it directly to your coding agent (Claude Code, Codex, Cursor, ChatGPT) and have it wire the whole thing up for you. Paired with a shorter plain-text MCP setup guide for wiring Bench Studio into Claude Code, Codex, or Cursor as an MCP server, so an agent can generate images and videos, check spend, and build websites or documents on your behalf, using the same backend as the visual interface.
