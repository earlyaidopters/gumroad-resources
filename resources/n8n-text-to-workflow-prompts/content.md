# n8n Text-to-Workflow Prompts ⚡️
## Sample Prompts

```
Create an automated lead qualification workflow with the following requirements:

- Trigger: New contact from Calendly booking
- Storage: Contact saved to GoHighLevel CRM
- Enrichment: Use OpenAI API to analyze the prospect's information, including:
  - Extract and research their company domain
  - Perform deep company research via Perplexity API or similar tool
  - Assess company reputation and qualification criteria
- Data logging: Store all research findings in the appropriate CRM fields
- Notification: Send email alert to my Outlook account when a lead qualifies as reputable
- Define clear qualification criteria for what constitutes a 'reputable company'
```

```
Generate mock JSON data that simulates a Calendly webhook payload for a new booking event. Include all standard fields typically sent by Calendly's webhook for testing purposes in a workflow node.
```

```
Extend the existing workflow to include:

- Integration: Listen for Fireflies meeting transcripts
- Analysis: Use AI to evaluate the transcript and determine prospect fit based on defined criteria
- Decision branch: If prospect is not an ideal fit, trigger automated nurture sequence
- Nurture campaign: Design a multi-touch sequence including:
  - Email series with relevant content
  - Educational collateral distribution
  - Suggested timeline and cadence
- Provide specific examples of nurture content and criteria for determining poor fit
```
